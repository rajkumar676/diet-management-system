# Diet Management System (DMS) - Frontend MVP

## Project Overview
Diet Management System (DMS) is a MERN stack application designed to provide personalized expert guidance by pairing users with specialized guides. This frontend MVP built with React, TypeScript, and Material-UI (MUI v5) supports dual-role functionality for Guides and Users with secure OTP-based authentication.

## Features
- Responsive and professional UI using Material-UI v5
- Public marketing pages: Home, About Us, Contact
- User registration with phone/email and OTP verification
- Role selection and onboarding for Guide specializations
- Secure login with JWT stored in context and localStorage
- Protected routes based on authentication status and user role
- Role-based dashboards (placeholders)
- API integration via Axios with JWT authorization headers

## Prerequisites
- Node.js (version 18.x or later recommended)
- npm (version 9.x or later recommended)
- Backend API endpoint compatible with the frontend (Express.js recommended)
